Private by design

Python runs in your browser via Pyodide. The PDF you select is parsed locally — no upload, no server, no telemetry. Disconnect your network after the page loads if you want to be sure.

Variant-aware

Different operators and MIS systems produce different OCCM layouts. Cypher detects the format from page-1 text and dispatches to a parser tuned for it.

Soft validation

Every cell is checked against aviation conventions (uppercase codes, no O/I in part numbers, ATA chapter range, etc.). Suspicious cells are flagged for analyst review — never silently dropped.
